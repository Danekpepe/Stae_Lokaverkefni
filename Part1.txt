Part 1: Finite Difference Method and the Heat Equation
Task: Find a numerical solution for the 1D heat equation: ∂ₜu = κ∂ₓ²u.

Grid Preparation:

Define space steps (h = L/N) and time steps (τ = T/M).

Use "forward difference" for time derivatives and "central difference" for space derivatives.

Programming:

Create a function: function HW = heatwave(L, T, N, M, psi, phi, f).

Solve the system Ac = b, where A is a P×P matrix (P = total nodes).

Use sparse matrices to speed up calculations.

Validation and Testing:

Test Run: Run with specific parameters (L=1, T=1/20, N=6, M=4) and compare against provided results.

Exact Solution: Compare numerical results (HW) against the analytical Fourier series solution for specific boundary conditions.

Energy Analysis: Verify that energy E(t) is a decreasing function over time (not conserved) for Dirichlet/Neumann conditions.

Stability: Note that numerical stability requires σ = (τκ)/h² ≤ 1/2.
