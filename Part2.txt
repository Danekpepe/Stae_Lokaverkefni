Part 2: Poisson Equation and Finite Element Method (FEM)
Task: Approximate the 2D Poisson equation (-Δφ = f) using FEM on a triangular mesh.

Grid Preparation:

The domain D is a rectangle [0, L1] x [0, L2].

Divide the area into right-angled triangles with sides h and k.

Programming:

Create a function: function PE = PoissonEq(L1, L2, h, k, ub, ut, vl, vr, f).

Explain in the report how matrix A and vector b are constructed.

Validation and Testing:

Test Run: Run with specific parameters (L1=L2=1, h=1/5, k=1/4) and verify against provided sample output.

Exact Solution: Compare the numerical result PE against the analytical solution φ(x,y) = e^(-xy).

Gauss's Law: Verify the numerical fulfillment of Gauss's Law (charge density vs. flux). Show that the error E_G decreases as the grid is refined (h → 0).
